# 03 - Data Model (Zyndi Auralia Wibowo)

Folder ini berisi artefak tugas **Data Modeler** untuk proyek Data Warehouse Kelompok 5 dengan proses bisnis **Online Sales** menggunakan database sumber AdventureWorks PostgreSQL.

## Isi folder
- `star-schema-v1.md` — rancangan grain, fact table, dimension table, dan aturan perhitungan.
- `bus-matrix.md` — pemetaan proses bisnis terhadap dimensi.
- `star-schema-diagram.mmd` — diagram Star Schema dalam format Mermaid.
- `data-model-notes.md` — asumsi, keputusan pemodelan, dan hal yang perlu divalidasi.

## Status
Rancangan ini merupakan **Star Schema V1 (logical design)**. Nama kolom dan relasi perlu dicocokkan kembali dengan struktur tabel sumber serta disepakati bersama tim sebelum implementasi fisik.

## Cara melihat diagram
Buka `star-schema-diagram.mmd` di VS Code dengan ekstensi Mermaid, atau tempelkan isinya ke Mermaid Live Editor.
