# Data Source & Profiling — Vernanda Pramudya Sejati

Folder ini berisi dokumentasi database sumber AdventureWorks dan hasil profiling awal untuk proyek Data Warehouse Kelompok 5 dengan proses bisnis **Online Sales**.

## Isi folder
- `source-database.md` — informasi dan persiapan database sumber.
- `source-tables.md` — tabel sumber yang digunakan.
- `data-profiling.sql` — query SQL untuk profiling.
- `data-profiling-results.md` — ringkasan hasil profiling yang telah diperoleh.
- `evidence/` — tangkapan layar bukti pengerjaan.

## Catatan
Database sumber menggunakan PostgreSQL dengan nama `adventureworks`. Database target Data Warehouse direncanakan bernama `dw_kelompok_5`.

File database dan seluruh CSV sumber tidak disertakan dalam repository ini. Dokumentasi dan query disimpan agar proses dapat ditelusuri tanpa mengunggah dataset berukuran besar.
